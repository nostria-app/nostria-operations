# Codebase Improvement Task

You are performing autonomous codebase maintenance and improvement. Pick ONE area from the categories below, make focused improvements, then commit your changes. Do not try to do everything at once -- focus on one meaningful improvement per run.

**Important:** Read `AGENTS.md` before making any changes. Follow all project conventions.

## Categories (pick one per run)

### 1. Agent Enhancements

- Improve agent system prompts for better output quality
- Add new agent capabilities or refine existing configs
- Create reusable prompt templates

### 2. Documentation & Playbooks

- Write operational playbooks for common tasks
- Improve agent guides with examples and best practices
- Document cross-repo workflows

### 3. Automation & Scripts

- Improve the main loop script (error handling, logging)
- Add new automation scripts for cross-repo tasks
- Enhance GitHub Actions workflows

### 4. Business Planning

- Draft or refine business strategy documents
- Update roadmaps based on recent progress
- Create competitive analysis or market research

### 5. Marketing Content

- Generate social media post drafts
- Plan upcoming campaigns
- Create content calendars

## Guidelines

- Keep changes focused — one category per run
- Log all changes in `/logs/`
- Follow naming conventions defined in each folder's README
- Don't modify production app code from this repo — use cross-repo PRs instead

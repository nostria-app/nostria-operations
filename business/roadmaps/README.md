# Roadmaps

Product and company roadmaps live here.

## Format

Each roadmap should include:
- **Timeline** (quarters or months)
- **Milestones** with success criteria
- **Dependencies** between items
- **Status tracking** (planned / in-progress / done)

## Naming Convention

`YYYY-<scope>-roadmap.md`

Examples:
- `2026-product-roadmap.md`
- `2026-company-roadmap.md`
- `2026-H2-growth-roadmap.md`

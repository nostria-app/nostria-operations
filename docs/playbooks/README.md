# Playbooks

Operational playbooks for common tasks and procedures.

## What Goes Here

Step-by-step guides for recurring operations:

- **Deployment playbook** — how to ship a new version
- **Incident response** — what to do when something breaks
- **Release checklist** — pre/post-release steps
- **Onboarding** — setting up a development environment
- **Marketing launch** — steps for a feature launch campaign

## Template

```markdown
# Playbook: [Name]

## Purpose
[What this playbook covers]

## Prerequisites
- [requirement]

## Steps
1. [step]
2. [step]
3. [step]

## Rollback / Recovery
[What to do if things go wrong]

## Last Updated
[Date]
```

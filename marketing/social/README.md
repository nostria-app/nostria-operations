# Social Media Posts

Generated social media content ready for review and publishing.

## Naming Convention

`YYYY-MM-DD-<platform>-<description>.md`

Examples:
- `2026-02-08-nostr-feature-announcement.md`
- `2026-02-08-twitter-thread-why-nostria.md`

## Status Tracking

Each post file should include a status header:

```markdown
---
status: draft | reviewed | published
platform: nostr | twitter | blog
date: YYYY-MM-DD
---
```

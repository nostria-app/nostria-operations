# Marketing Assets

Generated images, graphics, copy, and media files.

## Naming Convention

`YYYY-MM-DD-<type>-<description>.<ext>`

Examples:
- `2026-02-08-banner-new-feature.md` (description/prompt for image)
- `2026-02-08-copy-launch-announcement.md` (marketing copy)

## Notes

- Store image generation prompts as `.md` files
- Actual images can be stored here or linked from external hosting
- Keep file sizes reasonable — avoid committing large binary files

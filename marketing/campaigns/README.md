# Marketing Campaigns

Campaign plans, execution tracking, and post-mortems.

## Structure

Each campaign gets its own folder or file:

```
/campaigns
  /2026-Q1-launch/
    plan.md
    results.md
  2026-02-feature-announcement.md
```

## Campaign Plan Template

```markdown
# Campaign: [Name]

## Goal
[What success looks like]

## Target Audience
[Who we're reaching]

## Channels
- [ ] Nostr
- [ ] Twitter/X
- [ ] Blog
- [ ] Other

## Timeline
- Start: [date]
- End: [date]

## Content Plan
1. [Post/content item]
2. [Post/content item]

## Success Metrics
- [Metric]: [Target]

## Results
[Fill in after campaign ends]
```

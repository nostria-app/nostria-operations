# Materials Checklist (Minimum Effective Kit)

This is the smallest set of assets that supports a 2-week sprint and a 4-8 week rollout.

## Web
- Landing page for v3: promise, 3 benefits, screenshots/GIFs, proof, CTA
- Human changelog: top 10 updates with "why it matters"
- Press kit page: logos, screenshots, boilerplate, quick facts, contact

## Social
- Share kit folder (images + copy): Nostr + X + Discord
- Proof thread (X) + proof note (Nostr)
- Starter Packs (curated follow lists) page(s) if feasible

## Video
- 60-90s demo video: "what it feels like" + 3 key workflows
- 10 short clips: 10-20s each (vertical-friendly)
- 15-25s quote montage: proof-first

## Discord/community
- #start-here onboarding message
- Weekly live onboarding/demo event (with recording)
- #love (testimonials) channel and a pinned "how to share a testimonial"

## Proof collection
- Permission request replies for quote usage
- Testimonial intake template
- Lightweight case study template (optional)

## Tracking
- UTM convention doc
- Funnel events definition: visit -> signup -> follow 5 -> first meaningful interaction -> D7 return

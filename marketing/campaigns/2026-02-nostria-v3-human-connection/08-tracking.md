# Tracking and Measurement

Replace placeholders using `marketing/social/2026-02-nostria-v3/variables.md`.

## Metrics
North star (suggested): meaningful interactions per active user.

Activation funnel (suggested):
- Landing visit
- Signup / first open
- Follow 5 accounts
- First meaningful interaction (reply/DM)
- D7 return

Virality:
- Invites sent per activated user
- Invite conversion rate
- Shares of quote cards / Nostria Card

## UTM convention
Use a consistent scheme:

- utm_source: nostr | x | discord | partner
- utm_medium: social | community | dm | event
- utm_campaign: nostria_v3_human_connection
- utm_content: proof_01 | clip_02 | starterpack_privacy | etc

Example:
{{CTA_URL}}?utm_source=x&utm_medium=social&utm_campaign=nostria_v3_human_connection&utm_content=proof_01

## Weekly review questions
- Which post format drove activated users (not just clicks)?
- Which proof quote performed best by saves/shares?
- Where does onboarding drop (follow 5, first reply, etc)?
- Which partner/community drove the best retention?

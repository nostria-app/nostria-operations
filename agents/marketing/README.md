# Marketing Agent

The marketing agent handles social media presence, content generation, and campaign planning.

## Capabilities

- Generates social media posts (text, threads)
- Plans and tracks marketing campaigns
- Suggests content ideas based on app features and trends
- Drafts blog posts and announcements
- Analyzes engagement metrics

## How It Works

1. Triggered manually or on a schedule
2. Reads current app features, recent changes, and roadmap
3. Generates marketing content in `/marketing/`
4. Can open PRs to `nostria-website` for blog posts

## Configuration

See `config.yaml` for parameters.

## Prompts

- `system-prompt.md` — The agent's personality and content style
